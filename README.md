# آشپزیار

آشپزیار یک اپلیکیشن اندروید آفلاین برای آشپزی روزمره، مدیریت انبار مواد، برنامه‌ریزی وعده و خرید هوشمند است. همه داده‌ها روی دستگاه می‌مانند؛ هیچ سرور، حساب، تبلیغ یا ردیابی وجود ندارد.

## قابلیت‌ها
- **۱۵۰ دستور واقعی** در ۱۵ دسته، با مواد، مراحل، تایمر و نکته‌های پخت.
- **آشپزخانه هوشمند:** درصد تطابق دستور با موجودی، جایگزین مواد و فهرست کمبودها.
- **برنامه هفتگی:** تولید برنامه با فیلتر گیاهی، بودجه، زمان و آلرژن.
- **فهرست خرید:** تجمیع خودکار از وعده‌ها، کسر انبار، قیمت واقعی و تاریخچه.
- **حالت پخت:** مراحل تمام‌صفحه، تایمر هر مرحله و اعلان.
- **انبار:** یخچال/فریزر/کابینت، تاریخ انقضا، مصرف اتمیک و بازگردانی.
- **هزینه، باقی‌مانده غذا، ترجیحات، مبدل واحد، نکته‌های ایمنی و پشتیبان JSON.**
- **فارسی کامل:** RTL، تقویم جلالی، اعداد فارسی، تم روشن و تیره.

## ساخت
بیلد فقط در GitHub Actions انجام می‌شود. Workflow روی هر Push اجرا می‌شود و این خروجی‌ها را می‌سازد:

- `ashpazyar-debug.apk`
- `ashpazyar-release.apk`
- `ashpazyar-release.aab`

برای امضای Release، این Secretها را در مخزن تنظیم کنید:

| Secret | توضیح |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | فایل Keystore با Base64 |
| `ANDROID_KEYSTORE_PASSWORD` | رمز Keystore |
| `ANDROID_KEY_ALIAS` | نام Alias کلید |
| `ANDROID_KEY_PASSWORD` | رمز کلید |

بدون این Secretها، خروجی Release بدون امضا ساخته می‌شود و برای انتشار فروشگاه آماده نیست.

## نصب
1. تب **Actions** را باز کنید.
2. آخرین Workflow موفق را انتخاب کنید.
3. از بخش Artifacts، فایل `ashpazyar-build-...` را دانلود کنید.
4. `ashpazyar-debug.apk` را روی دستگاه اندروید ۸ به بالا نصب کنید.

## داده و حریم خصوصی
- داده اولیه از دارایی‌های محلی بارگذاری می‌شود.
- فهرست خرید و برنامه‌ها فقط در Room ذخیره می‌شوند.
- پشتیبان‌گیری با انتخاب فایل توسط خود کاربر انجام می‌شود.
- اپ هیچ مجوز اینترنت ندارد.
