# چاشیکا

چاشیکا یک اپلیکیشن اندروید آفلاین برای آشپزی روزمره، مدیریت انبار مواد، برنامه‌ریزی وعده و خرید هوشمند است. محتوای اصلی روی دستگاه است؛ هیچ سرور محتوایی، حساب کاربری، تبلیغ یا تحلیل رفتاری وجود ندارد.

## قابلیت‌ها
- **۷٬۷۹۰ رکورد دستور:** ۲٬۰۰۰ دستور نمونه با مواد و مراحل (۱۵۰ دستور پایه و ۱٬۸۵۰ نسخه تولیدشده با قواعد آشپزی) و ۵٬۷۹۰ رکورد کاتالوگ `Persian_Cooking` با مواد اما **بدون مراحل پخت**.

> **وضعیت داده:** هدف ۵۰٬۰۰۰ دستور دارای آموزش کامل است. مجموعه فعلی نمونه اولیه است، هیچ رکوردی `VERIFIED` نیست و به‌عنوان دانشنامه تأییدشده منتشر نمی‌شود. ۵٬۷۹۰ رکورد واردشده از `train.csv` به‌صورت `REVIEW_REQUIRED` نمایش داده می‌شوند و حالت پخت آن‌ها غیرفعال است. منبع در Hugging Face با مجوز MIT منتشر شده و انتساب آن در `THIRD_PARTY_NOTICES.md` ثبت شده است.
>
> **بسته دانشنامه جدید (خارج از Seed اپ):** پردازش `train.csv` با ۶٬۶۶۰ ردیف، ۵٬۷۹۰ دستور مستقل و ۵۲ محتوای غیرغذایی انجام شد. خروجی در `ashpazyar_dataset/` و `dist/ashpazyar_dataset.zip` است. منبع با مجوز MIT منتشر شده، اما چون مراحل پخت ندارد همه رکوردها `REVIEW_REQUIRED` هستند و نباید به‌عنوان دستور کامل ارائه شوند.
- **آشپزخانه هوشمند:** درصد تطابق دستور با موجودی، جایگزین مواد و فهرست کمبودها.
- **برنامه هفتگی:** تولید برنامه با فیلتر گیاهی، بودجه، زمان و آلرژن.
- **فهرست خرید:** تجمیع خودکار از وعده‌ها، کسر انبار، قیمت واقعی و تاریخچه.
- **حالت پخت گام‌به‌گام:** هر مرحله تا تأیید کامل، قفل می‌ماند؛ نوار پیشرفت مرحله‌ای، تایمر هر مرحله، اعلان و حفظ پیشرفت در چرخش صفحه.
- **انبار:** یخچال/فریزر/کابینت، تاریخ انقضا، مصرف اتمیک و بازگردانی.
- **هزینه، باقی‌مانده غذا، ترجیحات، مبدل واحد، نکته‌های ایمنی و پشتیبان JSON.**
- **فارسی کامل:** RTL، تقویم جلالی، اعداد فارسی، تم روشن و تیره.

## ساخت
بیلد فقط در GitHub Actions انجام می‌شود. Workflow روی هر Push اجرا می‌شود و این خروجی‌ها را می‌سازد:

- `ashpazyar-debug.apk`
- `ashpazyar-release.apk`
- `ashpazyar-release.aab`
- `ghashogh-bazaar.bin` (جداگانه، فقط برای آپلود در بازار)

برای امضای Release، این Secretها را در مخزن تنظیم کنید:

| Secret | توضیح |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | فایل Keystore با Base64 |
| `ANDROID_KEYSTORE_PASSWORD` | رمز Keystore |
| `ANDROID_KEY_ALIAS` | نام Alias کلید |
| `ANDROID_KEY_PASSWORD` | رمز کلید |

بدون این Secretها، خروجی Release بدون امضا ساخته می‌شود و برای انتشار فروشگاه آماده نیست.

## نصب و به‌روزرسانی
نسخه عمومی فقط از **برنامه بازار** نصب یا به‌روزرسانی می‌شود. چاشیکا هیچ APK را دانلود یا نصب نمی‌کند و مجوز `REQUEST_INSTALL_PACKAGES` ندارد.

صفحه محصول در بازار: `https://cafebazaar.ir/app/ir.ashpazyar.app`

خروجی‌های Actions برای بازبینی و انتشار در فروشگاه‌اند، نه مسیر دانلود کاربر نهایی.

## داده و حریم خصوصی
- داده اولیه از دارایی‌های محلی بارگذاری می‌شود.
- فهرست خرید و برنامه‌ها فقط در Room ذخیره می‌شوند.
- پشتیبان‌گیری با انتخاب فایل توسط خود کاربر انجام می‌شود.
- بررسی اختیاری به‌روزرسانی فقط یک مانیفست امضاشده را با HTTPS از GitHub Pages می‌گیرد؛ هیچ داده کاربر، شناسه دستگاه یا محتوای محلی ارسال نمی‌شود.
- هیچ تبلیغ، تحلیل رفتار یا سرور محتوایی وجود ندارد.
- دانلود و نصب فقط در بازار انجام می‌شود. جزئیات در `updates/README.md`.
